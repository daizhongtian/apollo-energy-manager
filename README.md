# Apollo Energy Manager

## Program Architecture

This is a small full-stack web application for managing projects and tasks. Users can create an account, log in, create projects, and add or update tasks. The frontend is built with React, while the backend uses Laravel REST API and Sanctum for authentication. User, project, and task data is stored in a relational database.
